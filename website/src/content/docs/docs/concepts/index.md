This section will explain the stable mental model behind the Runtime:

- **Workflows:** declarative YAML definitions and their step graph.
- **Runs:** durable executions with persisted state.
- **Steps:** deterministic, execution, and waiting capabilities.
- **Agents and tools:** LLM decisions operating through explicit tool contracts.
- **Waiting and resume:** durable suspension for human or external input.
- **Events and observability:** the ordered history of runtime behavior.

Until these concept guides are completed, start with the [demos](/docs/demos/) and use the source reference for exact contracts.
