This demo selects exactly one path from a root input. It does not require an LLM.

## Run a branch

```bash
skiller run --file examples/branching-workflow/flow.yaml --arg path=docs
```

Try `path=demo` or another value to exercise the default branch.

## What this proves

Agentic workflows do not need an LLM at every step. Deterministic routing stays explicit and testable in the YAML definition.
