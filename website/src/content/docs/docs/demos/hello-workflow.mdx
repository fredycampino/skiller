This demo passes a root input through an `assign` step and renders it in a `notify` step. It does not require an LLM or external service.

## Run it

From the repository root:

```bash
skiller run --file examples/hello-workflow/flow.yaml --arg name=Ada
```

The run reaches `SUCCEEDED` and its transcript contains `Hello, Ada!`.

## Inspect the run

Copy the `run_id` returned by the command:

```bash
skiller status <run_id>
skiller logs <run_id>
```

Use `status` for the current state and `logs` for the ordered runtime events.
