Connect a provider to start working with agents.

## Launch the Skiller TUI

Run `skiller` to open STUI, a terminal interface to run, observe, and interact with agentic flows.

```bash
skiller
```

## Choose your provider

On first launch, Skiller opens the provider setup automatically.

![Skiller on first launch, showing the LLM provider selection menu.](/images/docs/first-launch-provider-selection.svg)

Follow the setup until your connection is verified.

## Add more providers

Skiller supports multiple LLM providers. Type `/auth` in STUI whenever you want to add another provider.

![Command autocomplete in STUI with only / entered and auth highlighted among the available commands.](/images/docs/add-more-providers.svg)
