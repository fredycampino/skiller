## Meet Flows

Flows is the built-in Skiller agent for creating workflows and custom agents. Describe what you want to build, and Flows helps you turn the idea into an agentic flow.

## Start a conversation

Flows starts automatically after you complete authentication during the first-time setup.

You can also launch it at any time by typing this command in STUI:

```text
/run @flows
```

![STUI with /run @flows entered in the prompt, ready to launch the Flows agent.](/images/docs/run-flows.svg)

## Describe what you want to build

Ask Flows to create a workflow or a custom agent. For example:

> Help me create a custom agent that reviews Python code for readability and suggests improvements.

Or:

> Help me create a workflow that asks for a topic, drafts a short article, and lets me review it before saving.

Continue the conversation to clarify the requirements and refine the result.
